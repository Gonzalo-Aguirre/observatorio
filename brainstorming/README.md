# braninstorming
► Objetivo:
    Generar ideas de métricas que puedan incorporarse a futuros reportes.
    El foco no está en la precisión actual de los datos, sino en:
        Evaluar si cada métrica es medible
        Determinar si es relevante para el negocio
        Definir un posible proceso de obtención

► Alcance
    Los archivos dentro de esta carpeta:
    No representan reportes finales
    Pueden contener información incompleta o inconsistente
    Funcionan como exploración inicial de métricas

► Enfoque de trabajo
    Cada idea de métrica se analiza bajo tres criterios:
        1. Medibilidad
            ¿Se puede obtener el dato con los sistemas actuales?
            ¿Requiere nuevas fuentes de datos?
            ¿Es automatizable?
        2. Relevancia
            ¿Aporta valor al negocio o a la toma de decisiones?
            ¿Está alineada con objetivos estratégicos?
            ¿Evita redundancia con métricas existentes?
        3. Proceso de obtención
            Fuente de datos (DB, API, logs, etc.)
            Frecuencia de actualización
            Transformaciones necesarias
            Nivel de esfuerzo técnico

► Qué se espera encontrar acá
    Ideas crudas de métricas
    Pruebas de cálculo
    Análisis preliminares
    Posibles enfoques técnicos

    Priorizar según impacto vs esfuerzo
