# Reporte

► Objetivo:
    Desarrollar un sistema de análisis y automatización para la generación de reportes diarios del transporte público, contemplando el desempeño operativo por empresa, línea y unidad.

    El proyecto busca consolidar información proveniente de múltiples fuentes y transformarla en indicadores clave para la toma de decisiones.


► Datos Analizados
    El reporte incluye las siguientes métricas:

    → Corte de boletos
        Total general
        Por empresa
        Por línea
        Por coche (unidad)
    → Kilómetros recorridos
        Totales
        Efectivos
        Desagregados por empresa, línea y coche
⏱   → Frecuencias y velocidad comercial
        Por línea
        Por coche / interno
    → Liquidación
        Fecha de liquidación
        Cantidad de boletos liquidados
    → KPI principal
        IPK (Índice de Pasajeros por Kilómetro)

► Herramientas y Tecnologías
    → Excel
        Visualización de datos
        Formato final del reporte
    → Power Query
        Normalización y limpieza de datos
        Consolidación de archivos .xlsx y .csv
    → Power BI
        Modelado de datos
        Creación de dashboards
        Cálculo de métricas y KPIs
        Integración de múltiples fuentes (joins / merges)
    → Python
        Automatización del proceso de generación de reportes
        Procesamiento de datos

► Alcance del Proyecto
    Integración de múltiples fuentes de datos operativos
    Estandarización y limpieza automática
    Generación de reportes diarios consistentes
    Cálculo de indicadores clave de rendimiento (KPIs)
    Soporte para análisis operativo y toma de decisiones
