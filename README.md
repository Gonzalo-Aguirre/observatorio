# observatorio
Como analista de datos en el Observatorio de la Movilidad, trabajé con múltiples fuentes de información, incluyendo bases de datos SQL, así como la integración de datos provenientes de archivos .csv y Excel, según la empresa proveedora de la información.

Toda la información fue consolidada mediante un proceso de normalización, que incluyó la limpieza de datos y su estructuración, con el objetivo de integrarlos en una única base consolidada.

A partir de esta base unificada, se elabora un reporte diario orientado al análisis de la información. Este informe incluye métricas clave como:

Boletos emitidos, con un análisis detallado de su distribución
Kilómetros recorridos, incluyendo la comparación entre kilómetros productivos y efectivos
Flota operativa
Líneas en operación
Indicadores de rendimiento por empresa, línea, coche e interno
Frecuencia del servicio
Velocidad comercial

El indicador más relevante es el IPK (Índice de Pasajeros por Kilómetro), un KPI fundamental que permite evaluar la eficiencia del sistema en términos de demanda y oferta de transporte.
